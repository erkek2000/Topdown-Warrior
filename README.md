# Topdown Warrior

A 2D top-down action prototype featuring procedural environments, combatants, enemies, and dynamic light and shadow effects.

## Features

- Top-down player movement
- Slime enemies and reusable combatant logic
- Procedural world generation
- Transform, fade, and concealment areas
- Custom 2D shadows and environmental effects
- Desktop export included

## Getting started

1. Install Godot 4.4 or a compatible Godot 4 release.
2. Import `project.godot` in the Godot Project Manager.
3. Open the project and press **F6** or **F5** to run it.

The main scene is `scenes/test_grounds.tscn`.

## Project structure

- `art/` — characters, objects, particles, and tilesets
- `reusable_classes/` — reusable gameplay components
- `scenes/` — test grounds, entities, and world scenes
- `scripts/` — player, enemy, world-generation, and effects logic
